# 中国就业地图

参考 [Karpathy US Job Market Visualizer](https://karpathy.ai/jobs/) 的矩形树图交互，使用中国官方统计重做。源站按职业展示；本版按 **19 个国民经济行业门类** 展示，不能当成细分职业就业预测。

## 查看

直接用浏览器打开单文件 `china-jobs.html`，无需安装依赖或联网加载资源。也可打开 `dist/index.html`，或在本目录运行：

```sh
python3 -m http.server 8765 --directory dist --bind 127.0.0.1
```

访问 http://127.0.0.1:8765 。

## 数据

完整的来源、调查范围、参考年份、缺失值规则和 AI 分数边界见 [`DATA_SOURCES.md`](DATA_SOURCES.md)。页面右上角“数据与方法”也会展示同一套来源链接。

- 从业人数及女性人数：国家统计局《第五次全国经济普查公报（第二号）》表2-3，2023年末数据，2024-12-26发布。法人单位和个体经营户分开显示。
- 年平均工资与名义工资增速：国家统计局《2025年城镇单位就业人员年平均工资情况》表2、表5，2026-05-15发布。私营/非私营分开显示。
- AI任务暴露：Codex基于行业一般任务结构的主观评估，非官方、非失业概率、非经验证研究，不使用职业任务微观数据或就业权重。理由、限制和提示词可在界面查看。

`data/industries.csv` 是核对后的录入表；`data/raw/*-web.txt` 保存官方网页经浏览工具提取的快照，不是原始HTML。`dist/data.json` 含来源、参考年、发布日期、核对日期、快照SHA256和方法版本；`dist/data.js` 使离线打开也能工作。来源链接在页面和JSON内。

## 口径与缺失

经济普查不是全国所有就业人员的完整集合；农林牧渔仅含专业及辅助性活动，不包含全部农业就业。工资统计覆盖城镇地域内就业人数5人及以上法人单位，不含个体工商户、自由职业者，与经济普查人数不属于同一调查总体。

农业辅助活动无法直接对应工资表的完整农业门类，因此本版没有映射农业工资。金融业、公共管理个体经营户数字在原表为横线，保留 `null`；私营公共管理工资未发布，也保留 `null`。不将缺失数据当作零。

各行经四舍五入，法人单位人数之和为42898.2万人，官方合计为42898.4万人。矩形面积按各行数据，顶部合计采用官方值；未篡改任意一行来强行凑齐。

工资增速是2025较2024的名义工资增长，不是就业增速或未来增长预测。平均工资是税前年平均，不是中位数或到手工资。不能用地图人数将工资加权成全国工资。

## 更新与校验

当前为2026-10-08人工核对的静态快照，不自动更新。更新前核对两个官方表，保留网页提取快照；逐行更新CSV，再运行：

```sh
python3 scripts/prepare_data.py
python3 scripts/bundle_offline.py
node --check dist/app.js
node --check dist/treemap.js
```

数据生成脚本检查19个唯一行业、人数与女性人数关系、工资变化算术、缺失值和官方合计的舍入差额；失败会终止。浏览器原生HTML/CSS/JS，无第三方前端资源、无追踪、无API密钥。

支持浏览器WebMCP时暴露读取地图、切换地图和选中行业三个工具；普通浏览器不受影响。
